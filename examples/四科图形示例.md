#物理

##串联电路

::: draw

```typ
#import "@preview/cetz:0.5.3" as cetz
#align(center)[
#cetz.canvas({
 import cetz.draw: *
 let w =5.0
 let h =3.0
 //外框（左竖边在电池处留缺口）
 line((0,0), (0,1.42)); line((0,1.68), (0, h))
 line((0,0), (w,0)); line((w,0), (w, h))
 line((w, h), (0, h))
 //电池：两块水平板（长板=正极，短板=负极）
 rect((-0.32,1.64), (0.32,1.69), fill: black, stroke: none)
 rect((-0.19,1.40), (0.19,1.46), fill: black, stroke: none)
 content((-0.66,1.55), $E$)
 //电阻（上横边）
 rect((2.1, -0.16), (3.4,0.16), fill: white, stroke: black +0.8pt)
 content((2.75,0.48), $R$)
 //开关（右竖边，断开状态）
 line((w,1.15), (w +0.42,1.62), stroke: black +0.8pt)
 content((w +0.62,1.2), $S$)
 //电流方向箭头
 line((0.5, h), (1.1, h), stroke: rgb("#BE123C") +0.7pt, mark: (end: ">"))
 content((0.8, h +0.3), $I$, fill: rgb("#BE123C"))
})
]
```

:::

用 cetz原生画：矩形回路、电池（长短线）、电阻（矩形）、开关（斜线）、电流箭头。坐标即位置，改元件位置只改坐标。

##电路符号

::: draw

```typ
#import "@preview/zap:0.6.0"
#grid(columns:2, gutter:6pt,
 zap.circuit({ import zap: *
 node("A", (0,0)); resistor("r1", "A", (rel: (2.6,0)), i: $I$)
 }),
 zap.circuit({ import zap: *
 node("A", (0,0)); battery("b1", "A", (rel: (0,1.8)), v: $E$)
 }),
)
```

:::

zap提供 IEC标准符号，单个元件画得准。三个以上元件排布会挤在一起，所以复杂电路改用上一页那种 cetz手画。

##能力边界

|内容 |状态 |
|---|---|
|函数图、平面几何、线性规划 |可直接出图，参数化 |
|分子球棍、空间填充、VSEPR |14个预置分子，一行出图 |
|骨架结构式、化学方程式 |一行 SMILES /一行方程 |
|流程图、框图 |节点加边，位置可调 |
|电路图 |符号库可用，复杂电路需用 cetz手画坐标 |
|三视图、化学实验装置、物理实验器材 |暂无，需要手写 Typst代码 |
