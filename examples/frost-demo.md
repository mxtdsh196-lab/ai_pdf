# 磨砂玻璃效果演示

> 磨砂玻璃必须压在内容上才看得出来。在白纸上它就是一块浅色矩形。

## 1. 白纸上（看不出效果）

::: fx frost opacity=55 light=30 grain=1.8 grain-a=38
白纸上的磨砂，只能看到浅蓝底色
:::

## 2. 压在渐变上（真玻璃效果）

::: fx frost bg=gradient bg-c1=2547A8 bg-c2=BE123C bg-angle=120 opacity=40 light=25 grain=1.6 grain-a=42
磨砂玻璃压在渐变上，下层色彩透上来
:::

## 3. 同一背景，粗颗粒

::: fx frost bg=gradient bg-c1=2547A8 bg-c2=BE123C bg-angle=120 opacity=40 light=25 grain=3.2 grain-a=60 bar=4pt
颗粒放大近一倍，磨砂感更重
:::

## 4. 同一背景，颗粒极细

::: fx frost bg=gradient bg-c1=2547A8 bg-c2=BE123C bg-angle=120 opacity=40 light=25 grain=0.8 grain-a=30
颗粒极细，接近均匀的半透明
:::

## 5. 明亮配色

::: fx frost bg=gradient bg-c1=0EA5E9 bg-c2=F59E0B bg-angle=45 opacity=45 light=35 grain=2.0 grain-a=45
青橙渐变上的磨砂
:::

## 6. 深色配色

::: fx frost bg=gradient bg-c1=1E293B bg-c2=4C1D95 bg-angle=200 opacity=50 light=30 grain=1.8 grain-a=40
深色渐变上的磨砂，对比最明显
:::
