行内样式有这几种：==荧光高亮==、[语义色]{color=danger}、[指定色]{color=#BE123C}、[渐变字]{gradient=true}，以及徽章 [重点]{.badge .primary}。

##特效 fx

::: fx glow tone=primary strength=82 width=2pt
泛光：strength是描边透明度0~100，越大越淡；width是描边粗细。
:::

::: fx frost opacity=12 light=45 bar=2.5pt border=0.9pt
磨砂玻璃底：opacity是底色不透明0~100，light是高光条透明度。
:::

::: fx noise alpha=0.12
噪点：alpha是颗粒浓度0~1，写30也行，等于30%。
:::

::: fx gradient c1=BFDBFE c2=DDD6FE angle=135 strength=0.85
流体渐变：angle是光斑角度0到360，strength是浓度0到1。
:::

::: fx wave amp=8 color=EEF2F9
波浪分割线：amp是波幅1~40。
:::
