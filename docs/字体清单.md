## 三、字重写法

Typst 只认这几个名字：
`thin` `extralight` `light` `regular` `medium` `semibold` `bold` `extrabold` `black`

也可以直接写数字：`weight: 300` / `700` / `900`。**没有 `heavy`**（实测报错）。

## 四、踩过的坑

### 1. ITC Eras 六档字重一开始全失效

**根因**：从 cdnfonts 下的 woff 转 ttf 后，`Book/Demi/Medium/Ultra` 的 `usWeightClass` **全都是 500**，Typst 分不出来，三次修改 name 表都没用。

**修法**：统一 family 名为 `ITC Eras`，把 `usWeightClass` 设为 300/400/500/600/700/800，`nameID 2` 设为对应子族名。

```
ITCErasLightRegular.ttf   wc=300  sub=Light
ITCErasBookRegular.ttf    wc=400  sub=Book
ITCErasMedium.ttf         wc=500  sub=Medium
ITCErasDemiRegular.ttf    wc=600  sub=Demibold
ITCErasBold.ttf           wc=700  sub=Bold
ITCErasUltraRegular.ttf   wc=800  sub=Ultra
```

### 2. 不要给每档起独立 family 名

试过 `ITC Eras Light` / `ITC Eras Book` 各成 family，**Typst 会消失几个**。原因：Typst 把 `Light`/`Medium`/`Demi`/`Bold` 当样式词，试图从 family 名里剥离并按字重匹配，剥完发现这个 family 里没有对应字重，就整个不认。`Book`/`Ultra` 不是样式词所以能留。

**结论**：同一个 family + 正确的 usWeightClass 才是 Typst 的正路。

### 3. name 表要改全部平台

只改 platformID=3（Windows）不够，Typst 也读 platformID=0（Unicode）。但 platformID=0/3 要求 **UTF-16BE**，写成 latin-1 会变成 `䥔䌠䕲慳` 这种乱码并顶掉正常 family 名。

### 4. woff 转 ttf

```python
from fontTools.ttLib import TTFont
t = TTFont('in.woff')
t.flavor = None   # 去掉 woff 包装
t.save('out.ttf')
```

需要 `brotli`（woff2 才需要）和 `fontTools`，本机都有。

## 七、舟方日明体 Sthginkra（已补齐）

| 项 | 内容 |
|---|---|
| family 名 | `Sthginkra` |
| 字重 | Regular（不斜）+ Italic（斜） |
| 字形数 | 33,727 / 33,739 |
| 文件 | `Sthginkra-Regular.ttf` 8.9MB、`Sthginkra-Italic.ttf` 10.1MB |
| 授权 | **OFL-1.1**，可免费商用 |
| 来源 | ZeoSeven Fonts (ZSFT) item 633，作者绵雲飴里 |
| 底子 | Glow Sans SC Condensed Book 0.91（未来荧黑）+ Iosevka Fixed Curly 4.0.3 |

**字体特点**：黑体骨架 + 意大利斜体笔势，中文“意大利黑体”。覆盖 GB2312 6763 字 100%、Big5 高频 5401 字、JIS X 0208 日文汉字、假名、希腊文、西里尔文。

### 获取过程（值得记下来）

这个字体没有可下载的完整 ttf，只有 **cn-font-split 切成的分片 woff2**（Regular 204 片、Italic 216 片）。

做法：

1. 拿 CSS：`https://fontsapi.zeoseven.com/633/main/result.css`（斜体是 `/italic/`）
2. 正则提全部分片地址：`url("./<hash>.woff2")`
3. 逐片下载到本地目录
4. 用 `fontTools.merge.Merger` **每 40 片合一组**，再把各组结果合并（一次合 200+ 片内存会爆）
5. 改写 name 表：family=`Sthginkra`、Regular 设 Style=Normal、Italic 设 Style=Italic + macStyle bit1

关键点：**分片必须一个不差**。少一片就是少一批字，但 Typst 不会报错，只会静默回落字体，很难发现。

```python
from fontTools.merge import Merger
m = Merger()
f = m.merge(batch_of_40_paths)
f.save(out)
```

### 验证

```
fc-scan: Sthginkra|Regular  /  Sthginkra|Italic
typst fonts --variants: 同一 family 下两个 Style ✓
```
